The two sources do not receive identical generation information. The LLM sees device descriptions, rated power, aggregate statistics, parameter ranges, and the scorer description. The sampler uses the ranges and a seed. Once the candidates exist, however, the same deterministic scorer ranks every pool using aggregate power only. It combines residual fit, event agreement, state consistency, and separation, with weights of 0.35, 0.30, 0.20, and 0.15. No device-level test labels enter selection. We lock the chosen configuration before evaluating it against test labels. This design compares one-shot candidate sources under a common selector; it does not match generation time, cost, or information.
