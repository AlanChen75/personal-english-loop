The two sources do not receive identical generation information. The ell ell em sees device descriptions, rated power, aggregate statistics, parameter ranges, and the scorer description. The sampler uses the ranges and a seed. Once the candidates exist, however, the same deterministic scorer ranks every pool using aggregate power only. It combines residual fit, event agreement, state consistency, and separation, with weights of point three five, point three zero, point two zero, and point one five. No device-level test labels enter selection. We lock the chosen configuration before evaluating it against test labels. This design compares one-shot candidate sources under a common selector; it does not match generation time, cost, or information.
