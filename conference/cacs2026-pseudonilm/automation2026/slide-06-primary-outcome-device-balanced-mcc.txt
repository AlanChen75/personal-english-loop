Our primary outcome is load-state detection. M, C, C stands for Matthews correlation coefficient. For each device, we compare predicted on and off states with test labels. We count true positives, true negatives, false positives, and false negatives, then calculate one M, C, C for that device. The reported macro M, C, C is the arithmetic mean of the nine device M, C, C values. Each device receives equal weight, regardless of its duration or power rating. We average device scores rather than combine all devices into one confusion matrix. This test metric is separate from the aggregate-only selection score. We use test labels only after selection is locked. Event F-one is secondary.
