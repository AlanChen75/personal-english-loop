Our primary outcome is load-state detection. M, C, C stands for Matthews correlation coefficient. For each device, we compare its predicted on and off states with the test labels. We calculate one M, C, C score for each device. For macro M, C, C, we add the nine scores and divide by nine. Each device has equal weight. This test metric is separate from the aggregate-only selection score. We use test labels only after selection is locked. Event F-one is secondary.
