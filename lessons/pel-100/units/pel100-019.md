# 019｜週末計畫（Weekend Plans）

- Stable unit ID: pel100-origin-005
- Lesson ID: pel100-019
- Origin ID: 005

- 階段：1（難度僅為設計意圖）

## 原文

I'm going to visit my friends this weekend. We plan to have lunch together. If the weather is nice, we'll go for a walk. I hope we can spend more time together.

## T／L／E

- T 時態：未來式／第一類條件句
- L 邏輯：計畫→條件→期待
- E 表達：be going to；if
